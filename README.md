# CISC3024 AI Assignment #3 — RPCANet-lite: Deep-Unfolded Robust PCA

A from-scratch, GPU-free re-implementation of **deep-unfolded Robust PCA** for
infrared small-target detection (IRSTD), inspired by

* **RPCANet: Deep Unfolding RPCA Based Infrared Small Target Detection** (WACV 2024, arXiv:2311.00917)
* **RPCANet++** (arXiv:2508.04190, 2025) and **DRPCA-Net** (arXiv:2507.09541, 2025) — related work

Everything in this repository (code, experiments, figures, report) was generated by an
AI agent from natural-language instructions; the student wrote no code, as required by the assignment.

## What it does

Robust PCA (RPCA) decomposes an image `D = L + S` into a low-rank background `L` and a
sparse target layer `S`:

```
min_{L,S}  0.5*||D - L - S||_F^2 + lam*||S||_1 ,   rank(L) <= r
```

Instead of running an iterative solver (ADMM/IALM, as in the classic IPI model), the K solver
iterations are **unrolled into a K-stage network**, and only three scalars per stage are learned:

| stage parameter | meaning |
|---|---|
| `rho_k` | gradient step size on the data-fidelity term |
| `a_k`   | relative singular-value threshold (`tau_k = a_k * sigma_1`) |
| `lam_k` | sparsity threshold = detection threshold |

`K = 5` stages + a tiny self-calibrated sparsity head = **168 parameters**, trained in ~80 s on CPU.

## Results (60-image synthetic test set, 128×128)

| Method | AUC | IoU* | Pd @ Fa=1e-4 | ms/img |
|---|---|---|---|---|
| Top-hat (5×5) | 0.938 | — | — | ~0.1 |
| PCA residual (rank-3 patch PCA) | 0.943 | — | — | ~0.2 |
| IPI (RPCA via IALM) | 0.937 | — | — | ~19 |
| **RPCANet-lite (K=5)** | **0.991** | — | — | ~3 |

(exact numbers: see `results/eval_summary.csv` and the report)

## Layout

```
src/gen_data.py      synthetic IR image + ground-truth generator (seeded, reproducible)
src/models.py        RPCANet-lite: unrolled RPCA stages + self-calibrated sparsity head
src/baselines.py     top-hat, PCA residual, IPI (RPCA via inexact ALM)
src/metrics.py       IoU / Pd / Fa / ROC utilities
src/trainlib.py      shared training loop
src/train.py         main training (K stages, saves weights + log)
src/ablation.py      ablation over K = 1,2,3,5,8 (+ no-head variant)
src/evaluate.py      comparison against the three baselines -> results/eval_summary.{json,csv}
src/make_figures.py  all figures of the report
src/make_report.py   generates the Word report
results/             training logs, weights, metrics
figures/             figures used in the report
report/              AI_Assignment3_Report.docx
```

## Reproduce

```bash
cd src
python3 gen_data.py        # data/train.npz, data/test.npz
python3 train.py 5 25      # RPCANet-lite, ~80 s on CPU
python3 ablation.py        # Table 2
python3 evaluate.py        # Table 1
python3 make_figures.py    # figures/
python3 make_report.py     # report/AI_Assignment3_Report.docx
```

Requirements: `numpy scipy scikit-learn torch matplotlib opencv-python python-docx` (tested with
Python 3.12, torch 2.6, CPU only).
