RPCANet-lite: Deep-Unfolded Robust PCA for Infrared Small-Target Detection

CISC3024 Pattern Recognition - AI Assignment #3

A from-scratch, CPU-only re-implementation of deep-unfolded robust PCA (RPCANet, WACV 2024, arXiv:2311.00917) applied to infrared small-target detection. All code, experiments, figures and the report were generated by an AI agent; no code was written by the student.

Model

Y_k = L_(k-1) + rho_k (D - L_(k-1) - S_(k-1))
L_k = U soft(Sigma_k, a_k*sigma_1) V^T        # low-rank prox (SVD)
S_k = soft(D - L_k, lam_k)                    # sparse prox (L1)

168 parameters for K = 5 unrolled stages (3 scalars per stage + a self-calibrated sparsity head). Trained in 74 s on CPU.
